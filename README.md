# Diabetes Prediction API

REST API-сервис для инференса ML-модели (ONNX), предсказывающей вероятность
наличия диабета по клиническим признакам пациента.

## Возможности

- Эндпоинт `POST /predict` — предсказание на входе из четырёх признаков;
- Валидация входных данных (pydantic, строгая типизация и диапазоны значений);
- Базовая аутентификация (Basic Auth) для защищённых эндпоинтов;
- Логирование всех запросов и результатов инференса;
- Одиночная загрузка модели при старте приложения (без задержек на запрос);
- Контейнеризация (Docker / docker-compose);

## API

### `GET /`
Приветственный эндпоинт. Аутентификация не требуется.

```json
{ "message": "Добро пожаловать в Diabetes Prediction API" }
```

### `POST /predict`
Требует Basic Auth. Принимает JSON с признаками пациента.


## Запуск

### Локально
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000

### Docker
docker compose up --build -d

### Тесты
pip install pytest httpx
pytest -v
